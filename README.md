# STG: versiones

Acá se publican los instaladores de STG. Las STG instaladas revisan este lugar para actualizarse solas.

Para instalar por primera vez, entrá a **Releases** y bajá:

- **Windows**: `STG_<versión>_x64-setup.exe`
- **Mac**: `STG.app.tar.gz` (descomprimilo y mové STG a Aplicaciones; la primera vez abrila con clic derecho → Abrir)
